# Эвия

Вики кампании «Эвия».

- **[Для игроков](https://dariasavchenko-esl.github.io/aevia/)** — всё, что персонажи уже знают. Кнопка «Синхронизировать» подтягивает свежую версию.
- `gm.html` — страница мастера. Без токена GitHub она пустая: архив мастера лежит в закрытом репозитории.

`data/players.json` и `img/` обновляются автоматически, когда мастер синхронизирует архив. Руками их не правьте.
